# Prism 范围与验收

## 0.5.0 Mission增量（2026年10月28日）

新增明确工程委托下的目标驱动编排，允许实际当前Agent兼任产品负责人/架构师领导实现；对应规则及验收见[MISSION.md](MISSION.md)。支持CTF/Hackathon/Dev/REA、目标结构与业务/后端/部署方法落地、实际宿主编码与显式命令记录。下文“首版不自动修复/不自动执行开发需求”是原审计/Foundry范围，不能用于拒绝用户明确的Mission开发委托；它们的只读/规划权限也不能反向给Mission授权。未给具体目标时TARGET_REQUIRED，脚手架NOT_STARTED，云环境NOT_DEPLOYED。

本地工具不创建模型或专业逆向/抓取平台，不自行生成业务代码或证明业务正确；同用户执行不提供强隔离。新增合同明确源证据与推断、实际执行/验收/发布、身份声明的限制。验收必须包含实际可运行产物和同版本证据，不只检查目录或字段。

2026年10月27日。名称：Prism（棱镜）。仓库：jaminliu89/prism，私有。当前目标是可独立加载、可由集团路由的产品规划与审计Skill套件，不是新SaaS或自动化审计平台。

## 用户故事

1. 作为产品负责人，我给出仓库/URL/需求资料后，需要获得适用的审计计划与证据要求，避免被表面完成度误导。
2. 作为独立使用者，我只克隆Prism，也能读总控Prompt、使用规划Prompt/清单并保存审计记录，不依赖本机SkillHub绝对路径。
3. 作为集团执行者，我需要Prism与blueprint、checklist、site clone协作，复用固定版本方法，保留原交付/逆向/技术治理权限。

## 首版能力与DoD

| 能力 | 输入→输出 | 验收 |
|---|---|---|
| Skill/总控Prompt | 用户目标和材料→适用审计步骤、发现与边界 | 不假设工具可用，不把文档当运行证据 |
| 规划模式 | 点子→已有idea-to-blueprint Prompt | 0–6阶段确认，不写业务代码 |
| 审计计划 | 显式模式、目标类型、目标及revision→JSON计划 | 稳定选模块；无授权不升级为clone/发布/修复 |
| 离线源合同 | 锁定版本方法→本地只读快照 | doctor逐文件核对SHA；不依赖SkillHub运行环境 |
| 报告核验 | 报告JSON和本地证据→结构/摘要/版本检查 | 拒绝伪造PASS、错版本、越界路径、自验冒充独立审查 |
| 集团接入 | 根Registry→Prism薄适配入口 | 明确入口、固定提交、保留原走查/逆向主责 |

支持网页、App、桌面、API、CLI、服务和其他产品资料的分类入口。它不保证能自动审计一切产品：未能获取源码、设备、账号、运行日志或领域知识的部分必须标UNKNOWN/受阻。非软件产品可用需求/流程/证据框架，但具体法规、医疗、财务、安全等专业结论须相应有资格的专业人员/可用能力，不硬套软件清单。

不做：新抓取引擎、新浏览器、新模型网关、自动修复、自动发布、经营成功/PMF认证。既有核心交付/安全门禁不被本工具报告替代。

## 验证分层

单元测试覆盖计划与输入防护、锁定资产损坏、证据错版/篡改、伪独立身份与PASS误用。CLI实跑证明这些局部行为。真实产品完整审计、独立QA和工具端到端仍需后续实际目标证据。首版不将自身测试当作产品审计通过。


## Product Foundry V0.1 增量范围

用户在继续讨论后优先要求“从一句点子形成蓝图，并防止开发中 Agent 让产品偏航”。这次只给 Prism 增加一个**试验性、文件驱动的执行层**：复用 SkillHub 的 idea-to-blueprint 方法与独立文档合同，对阶段确认、原始意图、变更接受/拒绝、下游失效、模型无关 CLI 和只读 MCP 进行可复现测试。它不是已经能自动研究、自动多Agent协作的整个平台；这些缺口应按 [运行边界](FOUNDRY_V0_1.md) 验收，不得升级原 Prism 审计计划到产品自动完成声明。

原 Prism 的 plan/doctor/verify-report、上游快照锁和集团 Registry 不变。新增 CLI 独立运行，不宣称接管 CPO/PM、原设计、工程和独立QA的责任，也不自动执行用户提出的开发需求。

## V0.2：产品安全前置与角色交接

产品提案时即提示需要保护的核心资产、服务端/客户端信任边界和攻击者能力；架构阶段为七类潜在安全风险制定处置与隔离测试计划；最终蓝图包含安全复核与实际发布前的验证缺口。所有风险是**待判定的假设**，而非对某个产品已经存在漏洞的断言。逆向难度必须依赖授权测试和可复现证据，不能从混淆程度、文档完成度推导。

新任务为阶段限定的文档任务，不是已连接的数字员工或正式权限系统。任务可领取、交付、取消，旧输入失效后需要重新领取。正式授权、身份认证、自动Agent调用、隔离执行、测试靶场和真实安全审计不在本轮范围内。
